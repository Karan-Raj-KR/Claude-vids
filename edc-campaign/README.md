# EDC campaign film: Karan Raj KR

A 30-second campaign introduction film. It is 1920×1080 and 1080×1920, 60 fps, H.264 MP4, with an original synthesized soundtrack.

- **Finished files:** `deliverables/EDC-Karan-Raj-KR-16x9.mp4` and `deliverables/EDC-Karan-Raj-KR-9x16.mp4`
- **Storyboard:** `docs/STORYBOARD.md`
- **Still review notes and fixes:** `docs/REVIEW.md`

## v2: fast cut with the LEGO character

`deliverables/EDC-Karan-Raj-KR-v2-16x9.mp4` and `-v2-9x16.mp4` are the 27-shot fast-cut version, starring LEGO Karan from `assets/karan-character-sheet.webp`.

- **Poses:** `npm run cutouts` cuts the seven poses out to `public/karan/*.png`.
- **Shot list:** `timeline-v2.json` gives each shot's start, length and the sound its cut gets.
- **Shots:** `src/v2/shots.tsx` holds the shots and `src/v2/Reel.tsx` adds the cut smear and camera shake.
- **Soundtrack:** `npm run soundtrack:v2` rebuilds `audio/make_soundtrack_v2.py`. It has half-time trap drums, an 808 with glides, formant vocal chops, a delayed pluck lead, a stutter drop, a filtered breakdown, a key lift for the pledges, and a tape-stop into VOTE.
- **Render:** `npm run render:v2`.

## Edit the words or colours

Everything on screen comes from **`src/config.ts`**: all text, the five palette colours and the two typefaces. Change a value, then re-render.

- Add an election date in `TEXT.vote.date` (for example `"Voting: 24 Oct"`). It appears under "for EDC President".
- `KĀRYO` must keep its macron. The fonts include the latin-ext glyphs for both `Ā` and `₹`.

Timing (scene starts and BPM) lives in **`timeline.json`**. Both the video and the soundtrack generator read it.

## How it works

- Built with [Remotion](https://www.remotion.dev) (React + TypeScript). Every frame is a pure function of the frame number, using `useCurrentFrame()` → `interpolate()`. There are no CSS transitions and no timers.
- Rendering captures each frame in headless Chromium and encodes with ffmpeg.
- `src/scenes/*.tsx` holds the seven beats. `src/lib/geometry.ts` holds the shared positions of "the box", the vermilion square that carries across every cut.
- `audio/make_soundtrack.py` synthesizes the music and sound effects with numpy/scipy (120 BPM, every cut on a beat). There are no samples, so it is royalty-free.

## Commands

```bash
npm i                         # once
pip install numpy scipy       # once, for the soundtrack
npm run dev                   # live preview in Remotion Studio
npm run soundtrack            # regenerate public/soundtrack.wav
npm run render                # both MP4s → out/
npm run stills                # one still per beat → docs/stills/latest
```

In this cloud environment, rendering uses the pre-installed Chromium via `REMOTION_BROWSER`. On your own machine, Remotion downloads its own browser, so you don't need that variable.
